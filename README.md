## Описание проекта

Программа показывает непрерывный дождь на темном фоне средствами tkinter.
Капли равномерно движутся вниз, а после выхода за границу появляются сверху.
Глубина задает размер, яркость и скорость капель: дальние меньше и медленнее.

## Функциональные возможности

### Основной функционал

- Анимация падающих контрастных капель.
- Непрерывное поддержание заданного количества капель.
- Разделение логики движения и отрисовки.

### Дополнительный функционал

- Имитация глубины: разные длина, толщина, яркость и скорость.
- Плотность от 20 до 500 капель.
- Скорость от 0,2 до 3 от исходной.
- Пауза, продолжение и сброс.

## Требования к системе

- Python 3.9 или выше с tkinter и поддержкой графического окна.
- Windows, macOS или Linux с графическим рабочим столом.
- Модули стандартной библиотеки: tkinter, time, random, dataclasses, unittest.
- Сторонние пакеты не требуются.

Проверка tkinter: `python -m tkinter`. Должно открыться тестовое окно.
Если модуль отсутствует, установите компонент Tcl/Tk для вашей сборки Python.

## Установка и запуск

### 1. Получение проекта

Распакуйте архив и откройте терминал в папке `rain_animation`.
После публикации репозитория его также можно скачать через GitHub кнопкой
Code → Download ZIP или клонировать командой `git clone АДРЕС_РЕПОЗИТОРИЯ`.
Вместо `АДРЕС_РЕПОЗИТОРИЯ` подставьте реальный HTTPS-адрес своего репозитория.

### 2. Создание и активация виртуального окружения

Окружение зависит от компьютера. Даже если папка `venv` уже есть в проекте,
перед первым запуском на другом компьютере пересоздайте ее:

Windows (командная строка cmd):

```bat
python -m venv --clear venv
venv\Scripts\activate.bat
```

macOS / Linux:

```bash
python3 -m venv --clear venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

Файл содержит только комментарии: дополнительные пакеты не нужны.

### 4. Запуск

```bash
python main.py
```

### 5. Управление

| Элемент | Действие |
| --- | --- |
| Пробел / кнопка «Пауза» | Пауза и продолжение |
| R (К в русской раскладке) / «Сброс» | Новое распределение капель |
| Слайдер «Скорость» | Скорость движения |
| Слайдер «Капли» | Плотность дождя |
| Esc | Закрыть окно |

- `main.py` — точка входа.

для единственной модели и отрисовщика усложнили бы навигацию.

## Алгоритм анимации

Глубина d выбирается случайно от 0 до 1. Скорость равна `120 + 360*d`
пикселей в секунду, длина — `5 + 15*d` пикселей.
Каждый кадр координата обновляется по формуле `y = y + speed*dt*k`,
где dt — прошедшее время, k — значение слайдера скорости.
После выхода всей капли за нижнюю границу она возвращается наверх со случайной x.
События обрабатываются через `after(16, ...)`, без блокирующего цикла.
Для защиты от скачка после задержки dt ограничено 0,05 секунды.

## Пример использования

1. Запустите `python main.py`.
2. Установите 300 капель и скорость 1,5.
3. Сравните движение маленьких дальних и крупных ближних капель.
4. Нажмите пробел, измените плотность, снова нажмите пробел.
5. Нажмите R для сброса и Esc для выхода.
